# Significant Version Update Log

## v0.0.1 - 2025-09-30
- Had the initial idea to create a external editor
- With the help of AI, completed the node graph editing feature, and replicated the event node `When Node Graph Variable Changes` and execution node `Print String`
- Completed the import and export of JSON functionality

## v0.9.50 - 2025-10-08
- By uploading screenshots of nodes to AI, completed the definition of all server nodes
- Used AutoCAD to replicate some UI/icons used by the official editor

## v0.9.53 - 2025-10-14
- Inspired by [https://milidocs.tiiny.site/](https://milidocs.tiiny.site/), mirrored the official General Guide to local, in order to allow users who have not joined the official Miliastra Wonderland Creator Center to read the guides.

- Upgraded the node graph editor from sinle node graph editor to a node graph project editor, replicating the feature to edit various types of node graph, from the official editor
- By uploading screenshots of nodes to AI, completed the definition of some client nodes

## v1.0.0 - 2025-11-13
- Completed the definition of all client nodes
- Improved UI convenience and added mobile support

## v1.0.1 - 2025-11-21
