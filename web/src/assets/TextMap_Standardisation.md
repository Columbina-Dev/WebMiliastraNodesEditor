# 通用 | General
- 簡體及繁體中文文本内的單詞/數字一般無需在前後添加空格
- 日本語の単語/数字の前後にはスペースが必要です
- All languages use `「」` instead of `""` for quotes in UI texts. No need to add space before and after in English since they are full-width punctuations.
